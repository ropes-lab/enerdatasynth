# `data/reports/wind/`

Generated by `enerdatasynth evaluate --resource wind --preset <preset>` (`failure_analysis_<preset>.md`) and `enerdatasynth report --resource wind` (`results_summary.md`). This folder started out empty; its real fidelity-gate numbers still live primarily in `enerdatasynth.resources.wind.manifest.json`, and these reports just summarize or flag issues in those same numbers rather than computing anything new. Regenerated on every run, same convention as PJM load's [`../pjm_load/`](../README.md) reports — not hand-curated. See [`docs/models/wind.md`](../../../docs/models/wind.md) §7/§8 for the underlying numbers.
