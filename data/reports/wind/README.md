# `data/reports/wind/`

Generated by `enerdatasynth evaluate --resource wind --preset <preset>`
(`failure_analysis_<preset>.md`) and `enerdatasynth report --resource wind`
(`results_summary.md`) — added after this folder was originally empty (its own real
fidelity-gate numbers still live primarily in
`enerdatasynth.resources.wind.manifest.json`; these reports summarize/flag issues in
those same numbers, they don't recompute anything new). Regenerated on every run, same
convention as PJM load's [`../pjm_load/`](../README.md) reports — not hand-curated.
See [`docs/models/wind.md`](../../../docs/models/wind.md) §7/§8 for the underlying
numbers.
