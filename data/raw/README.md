# `data/raw/`

Raw source data, one folder per resource:

- [`pjm_load/`](pjm_load/README.md) — PJM/NOAA raw files `enerdatasynth preprocess` reads from.
- [`wind/`](wind/README.md) — placeholder; no raw wind data exists in this repository.

Neither is distributed with this package — see [`docs/data_card.md`](../../docs/data_card.md).
