This repository does not distribute raw PJM/NOAA data.

To run `enerdatasynth preprocess` from scratch, place these files in this folder
yourself:

  hrl_load_metered_2016.csv  through  hrl_load_metered_2025.csv
    -> PJM hourly metered load, "hrl_load_metered" data type.
       Source: PJM Data Miner 2 (https://dataminer2.pjm.com/), a public PJM tool
       covering the same fields used here (datetime_beginning_utc, zone, mw).

  pjm_hourly_temps_wide.csv, station_hourly_temps.csv
    -> Hourly temperature per PJM zone, built from NOAA's Integrated Surface
       Database (ISD) via src/enerdatasynth/data/temperature.py. That module
       fetches and caches this data itself (into data/cache/, also not
       distributed with this repository) given network access — you do not
       need to source these two files by hand if you run the pipeline
       end-to-end.

See docs/data_card.md and docs/models/pjm_load.md for exactly how this data is
cleaned once it's in this folder, and why raw data isn't bundled here.
