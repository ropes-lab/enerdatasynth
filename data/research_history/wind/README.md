# `data/research_history/wind/`

Empty on purpose. Wind's research history belongs to the separate, previously-published upstream project this package vendors as `enerdatasynth.resources.wind` — it isn't duplicated here. This folder exists as the resource-nested sibling of [`../pjm_load/`](../README.md), purely so the "one folder per resource, per category" pattern holds everywhere in `data/` and a future third resource's provenance folder is unambiguous to add. There's no historical material to put in it today.

If wind's original research history ever becomes available, it goes here.
