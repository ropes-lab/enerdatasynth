# `data/research_history/wind/`

Empty on purpose. Wind's research history belongs to the separate, previously-published
upstream project this package vendors as `enerdatasynth.resources.wind` — it isn't
duplicated here. This folder exists as the resource-nested sibling of
[`../pjm_load/`](../README.md) purely for structural consistency (so the
pattern "one folder per resource, per category" holds everywhere in `data/`, making a
future third resource's provenance folder unambiguous to add) — not because there's
historical material to put in it today.

If wind's original research history ever becomes available to include, it goes here.
